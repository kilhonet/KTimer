## 概要

映画を流したまま眠るとき、長いダウンロードやバックアップを走らせたまま席を離れるとき —「終わる頃にパソコンが勝手に切れてくれたら」と思うことがあります。

KTimer はボタン数回で時間を合わせて **実行** を押すだけ。フリップ時計が 0 まで数えたあと、パソコンをシャットダウンします。シャットダウンの代わりに **休止状態・スリープ** にすることもできます。

シャットダウンの直前には **そのときの画面をキャプチャしておき、次にパソコンを起動したときに見せてくれます。** 寝ている間にダウンロードが終わったか、どんなウィンドウが開いていたかを朝すぐに確認できます。

## 主な機能

- **予約シャットダウン** — 1 分から最大 7 時間まで、設定した時間が過ぎるとパソコンを切ります。
- **休止状態・スリープ** — 切る代わりに眠らせることもできます。この PC でできる方を自動で選びます。
- **終了直前の画面を確認** — シャットダウン直前の画面を保存し、次回起動時にブラウザで表示します。
- **フリップ時計** — 残り時間を時 : 分 : 秒の大きな数字カードでひと目で確認できます。
- **ボタンだけで時間設定** — `−5` `−1` `+1` `+5` で増減し、`5` `10` `30` でその値にすぐ設定します。
- **インストールも設定も不要** — 設定画面はなく、管理者権限なしで実行ファイル 1 つで動きます。
- **9 言語** — 韓国語・英語・日本語・中国語・ロシア語・イタリア語・フランス語・スペイン語・アラビア語。Windows の表示言語に従います。

## 使い方

### 基本の流れ

1. KTimer を起動します。画面の中央にウィンドウが開き、時計は **00 : 05 : 00**(5 分)で待機しています。
2. 時間ボタンで好きな時間に合わせます。例: `30` → 30 分、`30` のあと `+5` を 6 回 → 1 時間。
3. 電源アイコンで何をするか確認します。**電源マーク**ならシャットダウン、1 回押して **月** にするとスリープです。
4. **実行** を押します。時計が 1 秒ずつ減り、数字の間の点が点滅してカウント中であることを示します。
5. 0 になるとボタンが **シャットダウン中…**(または **休止状態に入る…** / **スリープ中…**)に変わり、パソコンが切れるか眠ります。KTimer も一緒に閉じます。

### 画面構成

| 要素 | 内容 |
|---|---|
| フリップ時計 | 残り時間(時 : 分 : 秒)。カウント中は中央の点が点滅します |
| `−5` `−1` `+1` `+5` | 予約時間をその分だけ減らす / 増やす(分) |
| `5` `10` `30` | 予約時間をその値(分)にすぐ設定 |
| 電源アイコン | 押すたびに **シャットダウン**(電源マーク)↔ **スリープ**(月)を切り替え。マウスを乗せると名前が出ます |
| **実行** / **停止** | カウント開始 / 停止 |

- カウント中は時間ボタンと電源アイコンが隠れ、**停止** だけが残ります。うっかり押して時間が変わることはありません。
- 予約時間は **1 分〜7 時間** です。それより減らしても増やしても、その端で止まります。

### こんなときは

**映画や音楽を流したまま眠りたい**
映画 1 本ならだいたい 2 時間前後です。`30` を押したあと `+5` で余裕をもって合わせ、**実行** を押しておやすみください。終わる頃にパソコンが切れます。

**ダウンロード・バックアップ・動画変換を走らせたまま席を離れる**
作業が終わりそうな時間に少し余裕を足して予約します(最大 7 時間)。次にパソコンを起動すると終了直前の画面が開くので、作業が本当に終わったかすぐに確認できます。

**シャットダウン直前にどんな画面だったか見たい**
KTimer がパソコンを切るときは **マウスがあったモニター** の画面を保存します。次に起動してサインインすると既定のブラウザが開き、その画面を表示します。特に操作は要りません。
- モニターが複数あるなら、確認したいウィンドウがあるモニターにマウスを置いてから席を離れてください。
- この画面表示は **シャットダウン** のときだけです。スリープは起こせば画面がそのまま残っているので必要ありません。

**保存していない文書があるとき**
予約時間になると、他のプログラムがシャットダウンを引き止めることなく確実に切れます。保存確認の画面で止まって一晩中点いたまま、ということがない代わりに、**保存していない内容は残らない** ので、実行する前に保存しておいてください。

**切らずに眠らせておきたい**
実行する前に電源アイコンを押して **月** にします。アイコンにマウスを乗せると、この PC で実際に行う動作が表示されます。
- **休止状態** — 開いているウィンドウと作業をそのまま保存して電源を切ります。再び起動するとその状態に戻ります。
- **スリープ** — ごくわずかな電力で待機します。すぐに復帰します。
休止状態が使える PC は休止状態を、使えない PC はスリープを使います。実行の直前にもう一度確認するので、待っている間に電源設定を変えてもそれに合わせて動作します。

**予約を取り消したい・時間を変えたい**
**停止** を押すとカウントが止まり、時間ボタンが再び表示されます。時間を直して **実行** を押すと、その時間から新しく数えます。完全に取り消すならウィンドウを閉じても構いません — ウィンドウを閉じると予約もなくなります。

**ウィンドウが邪魔**
ウィンドウを **最小化** しても裏で数え続けます。残り時間が気になったらタスクバーから開き直せば大丈夫です。

**ウィンドウがどこにあるか分からない**
KTimer をもう一度起動してください。新しく開かずに、すでにカウント中のウィンドウが前面に出てきます(予約は 1 つだけです)。

**時間を素早く合わせるコツ**
- よく使う 5・10・30 分はそのボタンを 1 回。
- 1 時間は `30` のあと `+5` を 6 回、45 分は `30` のあと `+5` を 3 回。
- 1 分単位は `+1`・`−1` で調整します。`−1` を押し続けても 1 分より下にはなりません。

## 設定

設定画面はなく、保存される設定もありません。起動するたびに次の状態で始まります。

| 項目 | 開始時の値 |
|---|---|
| 予約時間 | 5 分 |
| 動作 | シャットダウン |
| 画面 | ダークテーマ |
| 言語 | Windows の表示言語(未対応の言語なら英語) |

## 動作環境

- Windows 10・Windows 11(64 ビット)
- プログラムの実行に管理者権限や追加のランタイムは不要です。
- 終了直前の画面は既定のブラウザで開きます。インターネット接続はこの画面と新バージョンの案内にのみ使います。

## アップデート

KTimer は自動的にはアップデート **しません**。起動時に新バージョンの有無を確認して案内画面を表示し、**[はい]** を押すとダウンロードページが開いてプログラムが終了します。新バージョンは内部検証の後に手動で配布され、[KTimer ページ](https://v2.kilho.net/ktimer)で告知されます。[アップデートポリシー](https://en.kilho.net/archives/notice/2940)をご覧ください。
