## 概述

开着电影睡着的时候,挂着长时间下载或备份离开座位的时候 —— 总会想"要是结束时电脑能自己关掉就好了"。

用 KTimer,只需按几下按钮设好时间,再点 **运行**。翻页时钟倒数到 0 后,电脑就会关机。也可以不关机,而是让电脑进入 **休眠 · 睡眠**。

关机之前,KTimer 会 **截下当时的屏幕,等你下次开机时展示给你。** 睡觉期间下载是否完成、当时开着哪些窗口,早上一眼就能确认。

## 主要功能

- **定时关机** — 从 1 分钟到最长 7 小时,时间一到就关机。
- **休眠 · 睡眠** — 也可以不关机而让电脑睡眠。自动选择这台电脑支持的方式。
- **查看关机前的屏幕** — 保存关机前一刻的屏幕,下次开机时在浏览器中显示。
- **翻页时钟** — 剩余时间以时 : 分 : 秒的大号数字卡片显示,一目了然。
- **只用按钮设定时间** — `−5` `−1` `+1` `+5` 增减,`5` `10` `30` 直接设为该值。
- **无需安装和设置** — 没有设置窗口,不需要管理员权限,一个可执行文件即可运行。
- **9 种语言** — 韩语、英语、日语、中文、俄语、意大利语、法语、西班牙语、阿拉伯语。跟随 Windows 显示语言。

## 使用方法

### 快速上手

1. 运行 KTimer。窗口出现在屏幕中央,时钟已准备为 **00 : 05 : 00**(5 分钟)。
2. 用时间按钮设好想要的时间。例如:`30` → 30 分钟;`30` 后按 `+5` 六次 → 1 小时。
3. 看电源图标确认要执行的操作。**电源符号** 表示关机,按一下变成 **月亮** 表示睡眠。
4. 点击 **运行**。时钟每秒递减,数字之间的圆点闪烁,表示正在倒计时。
5. 到 0 时按钮变为 **正在关机…**(或 **进入休眠中…** / **正在睡眠…**),电脑随即关机或睡眠。KTimer 也会一起关闭。

### 界面构成

| 元素 | 作用 |
|---|---|
| 翻页时钟 | 剩余时间(时 : 分 : 秒)。倒计时期间中间的圆点闪烁 |
| `−5` `−1` `+1` `+5` | 将预定时间减少 / 增加相应分钟数 |
| `5` `10` `30` | 将预定时间直接设为该分钟数 |
| 电源图标 | 每按一次在 **关机**(电源符号)↔ **睡眠**(月亮)之间切换。鼠标悬停可看到名称 |
| **运行** / **停止** | 开始 / 停止倒计时 |

- 倒计时期间时间按钮和电源图标会隐藏,只留下 **停止**。不会因误按而改变时间。
- 预定时间范围为 **1 分钟 ~ 7 小时**。超出范围时会停在边界值。

### 这种情况怎么办

**开着电影或音乐睡觉**
一部电影一般 2 小时左右。先按 `30`,再用 `+5` 留足时间,点击 **运行** 后安心睡觉。快结束时电脑就会关机。

**挂着下载、备份、视频转换离开座位**
按任务大概完成的时间再多留一点余量来预约(最长 7 小时)。下次开机时会打开关机前的屏幕,可以马上确认任务是否真的完成了。

**想看关机前一刻是什么画面**
KTimer 关机时会保存 **鼠标所在显示器** 的屏幕。下次开机并登录后,默认浏览器会自动打开并显示该画面。你无需做任何操作。
- 如果有多台显示器,离开前把鼠标放在有你想确认的窗口的那台显示器上。
- 这个画面只在 **关机** 时提供。睡眠唤醒后屏幕原样保留,所以不需要。

**有未保存的文档时**
时间一到,其他程序无法拖住关机,电脑一定会关闭。不会因为停在"是否保存"的提示上而开一整夜,但 **未保存的内容不会保留**,请在运行前先保存。

**不想关机,只想让电脑睡眠**
运行前点击电源图标,切换成 **月亮**。鼠标悬停在图标上,会显示这台电脑实际将执行的操作。
- **休眠** — 保存打开的窗口和工作后断电。再次开机会回到原来的状态。
- **睡眠** — 以极少的电量待机,很快就能唤醒。
支持休眠的电脑使用休眠,不支持的使用睡眠。执行前会再确认一次,所以即使等待期间更改了电源设置,也会按新设置执行。

**想取消预约或更改时间**
点击 **停止** 后倒计时暂停,时间按钮重新出现。调整时间后点击 **运行**,会从该时间重新开始倒数。想彻底取消,直接关闭窗口也可以 —— 窗口关闭后预约也随之取消。

**窗口碍事**
把窗口 **最小化**,它会在后台继续倒数。想看剩余时间时,从任务栏重新打开即可。

**找不到窗口**
再运行一次 KTimer。不会打开新窗口,而是把正在倒数的窗口调到前面(一次只能有一个预约)。

**快速设定时间的技巧**
- 常用的 5 · 10 · 30 分钟,按对应按钮一次即可。
- 1 小时是 `30` 后按 `+5` 六次,45 分钟是 `30` 后按 `+5` 三次。
- 用 `+1` · `−1` 按分钟微调。一直按 `−1` 也不会低于 1 分钟。

没有设置窗口,也不保存任何设置。每次启动都以下列状态开始。
